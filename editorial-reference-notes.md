# Notas de referência editorial

## Padrões a reter

A referência de artigo observada organiza a leitura através de uma hierarquia nítida: navegação de categorias, identificação curta de autoria e tempo de leitura, um título dominante e uma introdução que antecede o conteúdo corrido. A plataforma Motor de Linha adotará este ritmo de leitura, mas sem replicar elementos de marca, cópia ou composição específica.

## Decisões para Motor de Linha

| Elemento | Decisão de design |
| --- | --- |
| Navegação | Categorias editoriais simples, alinhadas numa faixa superior e disponíveis num menu móvel. |
| Cabeçalho | Monograma tipográfico original, barra de edição e acento quadrado vermelho. |
| Artigo | Título de grande escala, metadados compactos, imagem de abertura e início de capítulo com capitular. |
| Ritmo | Secções curtas, citações em destaque e legendas discretas para imagens. |
| Galeria | Grelha fluida com pré-visualizações, legendas e leitor de ecrã inteiro. |
| Sistema visual | Branco, preto, cinzento técnico e vermelho editorial; grelha assimétrica e divisórias finas. |
